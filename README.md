# Multimodel-Dental-Caries-Classification-Segmentation-Using-Hybrid-CNN

## Overview
This repository contains the implementation of a hybrid deep learning model for the classification and segmentation of dental caries from radiographs. The project aims to automate the diagnosis of dental caries, reducing subjectivity and human error in traditional diagnostic methods. The model combines ResNet-50 for classification and ResUNet for segmentation, achieving high accuracy in detecting and localizing caries in dental radiographs.

### Key Features
Classification Model (ResNet-50): Accurately classifies dental radiographs into two categories: caries and non-caries.

** Segmentation Model (ResUNet):***  Precisely segments and highlights the affected regions in radiographs where caries are detected.

High Accuracy: The classification model achieves 87% accuracy, while the segmentation model achieves 98% accuracy.

User-Friendly Interface: Designed to be easily integrated into clinical settings, allowing non-technical users (e.g., dentists) to interact with the system.
